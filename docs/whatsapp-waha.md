# Бесплатная рассылка в WhatsApp через WAHA

[WAHA](https://github.com/devlikeapro/waha) — бесплатная программа. Она работает на сервере CRM,
подключается к WhatsApp центра по QR-коду (как WhatsApp Web) и отправляет сообщения от его имени.
CRM передаёт ей рассылку, и сообщения уходят сами — в личку и в групповые чаты.

## Установка — одна команда

Зайдите на сервер по SSH, перейдите в папку CRM и выполните:

```bash
cd /путь/к/english-center-crm
git pull origin main
sudo bash deploy/waha/install.sh
```

Скрипт сам:

1. поставит Docker, если его нет;
2. положит WAHA в `/opt/waha` и придумает ключи (файл `/opt/waha/.env`);
3. запустит WAHA — она слушает только сам сервер, из интернета её не видно;
4. впишет адрес и ключ WAHA в CRM.

Первый запуск — 3–5 минут (скачивается WAHA). В конце скрипт напишет «Готово!».

## Привязать WhatsApp — один раз

1. Откройте CRM → «Рассылки» → кнопка вверху справа (или сразу `https://ваш-сайт/broadcast/?setup=1`).
2. На телефоне с WhatsApp центра: **Настройки → Связанные устройства → Привязка устройства**.
3. Наведите камеру на QR-код. Через пару секунд CRM напишет «WhatsApp подключён».

Ниже на той же странице можно привязать группы CRM к групповым чатам WhatsApp.
После перезагрузки сервера QR-код сканировать заново не нужно.

## Если что-то не так

| Что случилось | Что сделать |
|---|---|
| Скрипт написал «✖ …» | Пришлите вывод скрипта целиком — разберёмся. |
| В CRM «Нет связи с WAHA» | `sudo docker ps` — должна быть строка `waha`. Если нет: `cd /opt/waha && sudo docker compose up -d` |
| Подключён ли WhatsApp? | `python manage.py setup_whatsapp --status` (в папке CRM) |
| Что пишет WAHA | `sudo docker logs waha --tail 50` |
| WhatsApp отвязался (на телефоне вышли из устройства) | Снова откройте «Рассылки» и отсканируйте QR-код. |
| Обновить WAHA | Запустите `sudo bash deploy/waha/install.sh` ещё раз — ключи останутся прежними. |
| Скрипт не нашёл Python от CRM | `sudo PYTHON=/путь/к/venv/bin/python bash deploy/waha/install.sh` |
| CRM сама работает в Docker | В CRM вместо `127.0.0.1` укажите адрес хоста, например `http://172.17.0.1:3000`, а в `/opt/waha/docker-compose.yml` замените `127.0.0.1:` на `172.17.0.1:`. |

Удалить WAHA совсем: `cd /opt/waha && sudo docker compose down`, затем `sudo rm -rf /opt/waha`
(вместе с этим отвяжется WhatsApp).

## Чтобы WhatsApp не заблокировал номер

WAHA — неофициальный способ, как и Green API: WhatsApp может ограничить номер, если примет
рассылку за спам. Поэтому:

- лучше завести для рассылок отдельный номер центра, а не основной;
- пусть родители сохранят этот номер в контакты, а лучше хоть раз напишут на него;
- CRM уже отправляет сообщения по одному с паузой 1,5–3 секунды — не убирайте её;
- не рассылайте одно и то же много раз подряд.
