# Настройки сервера: безопасность и резервные копии

Всё ниже делается в папке проекта на сервере (там, где `manage.py`).

## 1. Безопасность — что CRM делает сама

После обновления (`git pull`, `python manage.py migrate`, перезапуск сайта) CRM сама:

- **держит секретный ключ на сервере.** Если в `.env` нет `DJANGO_SECRET_KEY`, CRM один раз
  создаёт свой случайный ключ в `secret_key.txt` (в git не попадает). После этого всем придётся
  один раз войти заново — это нормально;
- **не показывает посетителям технические подробности ошибок.** Отладка выключена.
  Включить её на время (например, чтобы прислать ошибку программисту): `DJANGO_DEBUG=1` в `.env`
  и перезапуск сайта;
- **защищает от подбора пароля.** После 10 неудачных попыток для одного логина или 30 с одного
  адреса вход закрывается на 15 минут. Это работает и для `/admin/`. Счётчики общие для всех
  процессов сервера;
- **ведёт журнал входов.** Он в «Личном кабинете» → «Безопасность»: кто, когда, с какого
  устройства, удачно ли. Админ видит входы всех сотрудников, а каждый сотрудник может нажать
  «Выйти на других устройствах»;
- **выпускает из CRM только кнопкой «Выйти»,** а не ссылкой: чужой сайт не сможет выкинуть
  сотрудника из CRM;
- **показывает фото учеников и сотрудников, обложки и PDF книг только вошедшим.** Логотип виден всем;
- **требует нормальные пароли:** не короче 8 символов, не только цифры, не из списка самых
  простых и не похожий на логин;
- **по HTTPS ставит cookie входа флаг Secure и включает HSTS,** а также добавляет запрещающие
  заголовки (CSP, Permissions-Policy).

### Что проверить в nginx (один раз)

Чтобы CRM видела настоящий IP посетителя и понимала, что сайт открыт по HTTPS, в блоке
`location /` у nginx должно быть:

```nginx
include proxy_params;   # X-Real-IP, X-Forwarded-For и X-Forwarded-Proto
```

Не отдавайте `/media/` напрямую через nginx (`location /media/ { alias …; }`). Иначе фото и книги
будут открываться по прямой ссылке без входа.

### Если сайт открывают по другому адресу

Адреса, на которых работает CRM, перечислены в `config/settings.py`. Новый адрес добавляется
в `.env`, без правки кода:

```env
DJANGO_ALLOWED_HOSTS=crm.example.kz,1.2.3.4
```

### Обновления Django

Раз в месяц ставьте исправления безопасности:

```bash
pip install -U -r requirements.txt
```

Затем перезапустите сайт. В `requirements.txt` указана ветка Django 5.2 (LTS),
поэтому обновление ничего не ломает.

## 2. Резервные копии базы каждый день

Все ученики, группы, уроки и оплаты лежат в одном файле `db.sqlite3`. Если сервер сломается или
файл повредится — без копии всё пропадёт.

Ручная копия (проверить, что работает):

```bash
python manage.py backup_db
```

Копия появится в папке `backups/`, хранятся последние 30.

Каждый день в 3 ночи — откройте расписание командой `crontab -e` и добавьте строку
(путь к проекту и к python замените на свои; узнать их — команды `pwd` и `which python`):

```cron
0 3 * * * cd /путь/к/english-center-crm && /путь/к/python manage.py backup_db >> backups/backup.log 2>&1
```

Копия на том же сервере не спасёт, если сломается сам сервер. Поэтому раз в неделю скачивайте
копию к себе: «Профиль» → «Скачать копию базы» (у админа), или через поиск Ctrl+K → «Скачать копию базы».

## 3. Как восстановить базу из копии

1. Остановите сайт.
2. Сохраните текущую базу на всякий случай: `cp db.sqlite3 db.sqlite3.broken`
3. Положите копию на её место: `cp backups/db-20261016-0300.sqlite3 db.sqlite3`
   (или скачанный файл `enjoy-english-….sqlite3`).
4. Запустите сайт.

## 4. Погода на главной

Фон панелей приветствия и часов показывает погоду в Алматы прямо сейчас: солнце, облака, дождь,
ливень, снег, туман, гроза, а ночью — звёзды и луна в её настоящей фазе. Настраивать ничего не нужно.

- **Откуда данные:** MET Norway (Норвежский метеоинститут, api.met.no) — бесплатно, без ключа,
  можно и для бизнеса (источник указан в подсказке у погоды). Сайт спрашивает прогноз сам, не чаще
  раза в 10–30 минут, и хранит его в кэше на сутки — сотрудники в MET не ходят.
- **Нужен выход в интернет с сервера** (HTTPS). Проверить: `curl -sI "https://api.met.no/weatherapi/locationforecast/2.0/compact?lat=43.24&lon=76.91" | head -1`
  — должно быть `HTTP/2 200` (или `HTTP/1.1 200`).
- **Нет связи с MET** — погода не показывается, а небо всё равно меняется по солнцу (день, закат,
  ночь со звёздами): это считается на самом сервере. В журнале сайта будет строка
  «Погода: не удалось получить прогноз MET Norway».
- **Посмотреть любую погоду,** не дожидаясь её: `/dashboard/?weather=storm&time=night`.
  `weather`: sun, clouds, cloudy, fog, drizzle, rain, showers, heavyrain, storm, sleet, snow, heavysnow;
  `time`: day, morning, evening, dawn, dusk, night.

## 5. Интерактивные доски

Вкладка «Доски» в CRM: учитель подключается к доске кабинета и показывает на ней экран ноутбука,
ссылку (YouTube, Google Презентации, любой сайт) или файл (картинки, видео, звук, PDF). Пока он
подключён, другие эту доску занять не могут; доска освобождается кнопкой «Отключиться», когда закрыли
вкладку, или через полторы минуты без связи с ноутбуком. Админ и менеджер могут отключить кого угодно.

**Настройка доски (один раз, около минуты).**

1. CRM → Доски → «Добавить доску» (или шестерёнка на карточке) — откроется окно привязки.
2. На доске в Chrome наберите короткий адрес `enjoy-english.space/board` — на экране появится код
   из 6 цифр. Введите его в CRM и нажмите «Привязать» — доска сама откроет свою страницу.
3. На доске нажмите «Скачать установщик» и откройте файл. Chrome спросит про файл — «Сохранить»;
   Windows предупредит — «Подробнее» → «Выполнить в любом случае». Это всё.

Установщик (`dashboard/templates/dashboard/board_install.cmd`) кладёт в `%LOCALAPPDATA%\EnjoyBoard`
маленькую программу запуска и ярлыки: в автозагрузку и «Доска Enjoy English» на рабочем столе. Дальше:

- при включении доски она сама открывается на весь экран (дожидается сети, если Wi-Fi ещё не поднялся);
- окно доски закрыли — оно снова открывается свёрнутым и само выходит вперёд, когда учитель
  подключается или что-то показывает (даже поверх другой программы на доске);
- страница не загрузилась (сервер перезапускался, не было сети) — открывается заново;
- компьютер доски не засыпает и экран не гаснет, пока открыта доска.

Нужен Google Chrome (если его нет — подойдёт Microsoft Edge) и автоматический вход в Windows: если
при включении доска просит пароль, включите автовход (`netplwiz` → снять галочку «Требовать ввод
имени пользователя и пароля»). Журнал программы запуска — `%LOCALAPPDATA%\EnjoyBoard\board.log`.
Если сделали доске новую ссылку — привяжите её заново по коду и ещё раз запустите установщик.

**Как идёт экран.** Напрямую с ноутбука на доску по Wi-Fi центра (WebRTC, с шифрованием) — через
сервер идут только короткие служебные сообщения, поэтому сервер почти не нагружается. Нужно:

- ноутбук и доска в одной сети центра;
- в роутере выключена «изоляция клиентов» (AP / client isolation) — иначе устройства в Wi-Fi
  не видят друг друга, и CRM напишет «ноутбук и доска не видят друг друга по Wi-Fi».

Если изоляцию выключить нельзя, есть запасной путь через свой TURN-сервер (видео тогда идёт через
VPS и расходует его трафик):

```bash
sudo apt install coturn
# /etc/turnserver.conf: listening-port=3478, fingerprint, lt-cred-mech, user=board:ПРИДУМАЙТЕ_ПАРОЛЬ, realm=enjoy-english.space
sudo systemctl enable --now coturn      # и откройте порт 3478 (TCP и UDP) в файрволе
```

и в `.env` рядом с `manage.py`:

```
BOARD_TURN_URL=turn:enjoy-english.space:3478
BOARD_TURN_USER=board
BOARD_TURN_PASSWORD=ПРИДУМАЙТЕ_ПАРОЛЬ
```

После правки `.env` перезапустите сайт. Пароль TURN виден в браузере доски — придумайте отдельный,
только для coturn (не от сервера и не от CRM).

**Файлы до 100 МБ.** nginx по умолчанию принимает не больше 1 МБ — для видео поднимите лимит
в `server { … }` сайта и перезагрузите nginx:

```nginx
client_max_body_size 100m;
```

`sudo nginx -t && sudo systemctl reload nginx`. Файлы досок хранятся 3 дня в `media/board_files/`
(отдаются только доске по её секретной ссылке) и удаляются сами.
